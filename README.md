## Selected projects

### ProCardio

**From procedure notes to review-ready reports**

During my final-year internship at Ciprotec, I built a configurable cardiology workflow with hospital-scoped access, structured reports, and imaging suggestions clinicians can review. I prepared imaging data for model training and integrated document retrieval that cites its sources.

Reusing structured procedure information across review and reporting could reduce repeated entry and help teams produce more consistent reports.

**Stack** · React · TypeScript · Django REST Framework · PostgreSQL · PyTorch · YOLO · OCR · RAG · Docker

### OncoSense

**Preparing mammography data for lesion research**

I built an exploratory vision workflow that links mammograms to lesion masks, prepares traceable image manifests, and supports transfer learning and Faster R-CNN experiments. The crop preparation gives researchers a starting point for testing when a closer view of a lesion could help a model.

**Stack** · Python · PyTorch · Torchvision · pandas · OpenCV

[Case study](https://github.com/YASMINE712/OncoSense) · [Architecture](https://github.com/YASMINE712/OncoSense/blob/main/docs/technical-overview.md)

### My Health Friend

**Wellness ideas that fit into someone’s day**

Our team built a wellness planner that uses preferences, available time, and feedback to rank activity ideas. We evaluated activity prediction on held-out HeartSteps participants and used a separate contextual-bandit simulation to study how ranking responds to feedback.

The Random Forest activity classifier reached 0.731 ROC-AUC on a test split with six held-out participants. This setup gives teams a way to assess personalization ideas before testing them with users.

**Stack** · Python · Flask · pandas · scikit-learn · SQLite · Random Forest

[Repository](https://github.com/YASMINE712/patient-engagement-system) · [Model card](https://github.com/YASMINE712/patient-engagement-system/blob/main/docs/MODEL_CARD.md) · [Evaluation results](https://github.com/YASMINE712/patient-engagement-system/blob/main/docs/results/HEARTSTEPS_CLASSIFIER.md)

### MedRec CareFlow

**A clearer handoff from patient check-in to clinician review**

I built a demo that takes a patient check-in through a clinician review queue to a downloadable summary. The application combines role and ownership checks, encrypted fields, and integration tests with a reproducible ML baseline that uses synthetic data in the public demo. GitHub Actions tests the application and builds a Docker image for container delivery.

The review queue and shared summary could make it easier for both sides to track what was submitted and what happens next.

**Stack** · Flask · SQLAlchemy · Fernet · scikit-learn · Docker · GitHub Actions

[Repository](https://github.com/YASMINE712/medrec-careflow) · [Delivery pipeline](https://github.com/YASMINE712/medrec-careflow#containers-and-cicd)

### HayatCare

**A daily-care companion for older adults and caregivers**

This prototype brings cognitive activities, progress tracking, medication reminders, and optional caregiver notifications into one workspace. It also explores phone-motion signals, room-photo object detection, and a conversational information assistant. A shared view of routines and reminders could make caregiver follow-up easier.

**Stack** · Flask · SQLite · scikit-learn · YOLOv8 · Gemini API · Twilio WhatsApp

[Repository](https://github.com/YASMINE712/HAYAT-CARE) · [Product gallery and test evidence](https://github.com/YASMINE712/HAYAT-CARE/blob/main/docs/SCREENSHOTS.md)
